# 濟州旅遊 App｜2026/11/26–11/29

濟州 4 天 3 夜行程 app。手機打開網址就能用，也可以「加入主畫面」當 app，離線也看得到。

**App 網址：** https://45279798a-netizen.github.io/repo/

功能：
- 每天一張封面插畫（抵達日清晨、中山間火山丘、南部橘子田與懸崖、西部風車夕陽）
- 天氣預報（Open-Meteo，含體感溫度、降雨、風速）＋穿著建議；預報出來前顯示往年平均
- 每天的日出日落時間；看夕陽的站會算出當地日落時間
- 每餐 2–3 家在地餐廳，附營業時間、公休日（當天公休會標紅）、Kakao／Naver 連結
- 站與站之間的開車時間，排太趕會標出「會晚到幾分」
- 雨天備案：南部、西部各一條室內路線，預報下雨或大風時會提醒切換
- 四天分頁，旅行當天自動跳到今天、標出「下一站」
- 每天的路線小地圖，點編號跳到那一站
- 每一站一鍵開 Kakao 導航／Naver 地圖
- 「去過了」打勾（存在手機裡）

行程資料在 [`data/itinerary.json`](data/itinerary.json)，改這份檔案 app 就會跟著變。

## 資料格式

`data/itinerary.json` 中每個 stop 的欄位：

| 欄位 | 說明 |
|---|---|
| `time` | 預計抵達時間（當地時間） |
| `name` / `name_ko` | 中文名／韓文名（拿去 Naver Map、Kakao Map 搜尋用） |
| `lat` / `lng` | 座標，沒有固定地點時是 `null` |
| `category` | `experience` `walk` `nature` `history` `sunset` `food` `beach` `drive` `transport` |
| `duration_min` | 預計停留時間（分鐘） |
| `tips` | 小提醒 |
