# 濟州旅遊 App｜2026/11/26–11/29

濟州 4 天 3 夜行程 app。手機打開網址就能用，也可以「加入主畫面」當 app，離線也看得到。

**App 網址：** https://45279798a-netizen.github.io/repo/

底部五個分頁：

- **今天**：出發前是倒數、準備進度和出發那天的行程；旅途中是下一站、導航、天氣、日落和接下來的站
- **行程**：每天的封面、天氣、雨天備案、路線圖、時間軸、餐廳選項；加入旅行後可以新增、修改、調整順序
- **地圖**：所有地點在同一張圖，可以篩選某一天、吃的、雨天備案
- **清單**：「大家一起」和「我的」兩區，可以認領「我帶」
- **回憶**：每站的照片和心得，照片上傳前會自動壓小

### 一起用（Supabase）

朋友打開 app → 按「加入旅行」→ 輸入名字和通關碼，就會同步行程、清單和照片。

第一次設定：在 Supabase 開啟匿名登入（Authentication → Sign In / Providers → Allow anonymous sign-ins），
再把 [`supabase/setup.sql`](supabase/setup.sql) 裡的通關碼改掉，貼到 SQL Editor 執行。

連線設定在 [`js/config.js`](js/config.js)（只有公開的 publishable key）。沒加入或沒網路時，app 仍然能看行程。

行程資料在 [`data/itinerary.json`](data/itinerary.json)，改這份檔案 app 就會跟著變。

## 資料格式

`data/itinerary.json` 中每個 stop 的欄位：

| 欄位 | 說明 |
|---|---|
| `time` | 預計抵達時間（當地時間） |
| `name` / `name_ko` | 中文名／韓文名（拿去 Naver Map、Kakao Map 搜尋用） |
| `lat` / `lng` | 座標，沒有固定地點時是 `null` |
| `category` | `experience` `walk` `nature` `history` `sunset` `food` `beach` `drive` `transport` |
| `duration_min` | 預計停留時間（分鐘） |
| `tips` | 小提醒 |
